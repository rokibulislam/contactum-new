== Description ==

Contactum is a drag-and-drop form builder for WordPress — build contact forms without touching code, and
place them anywhere with a shortcode, block, widget, or the Elementor integration. Need payment forms,
subscriptions, or quiz scoring? Contactum Pro adds those on top.

Already running Contact Form 7, Gravity Forms, WPForms, Ninja Forms, Caldera Forms, or Fluent Forms?
Contactum can import your existing forms directly — fields, labels, and settings carried over automatically —
so switching doesn't mean rebuilding from scratch.

= Why Contactum =

* **Drag-and-drop builder** — arrange fields visually, no shortcode-memorizing required.
* **Migrate in one click** — import forms straight from Contact Form 7, Gravity Forms, WPForms, Ninja Forms,
  Caldera Forms, and Fluent Forms.
* **Entries built in** — every submission is stored and searchable, with CSV export, unlike plugins that only
  email you and forget.
* **Spam protection that doesn't slow visitors down** — an invisible honeypot field and a minimum-time-to-submit
  check run automatically on every form, alongside optional reCAPTCHA, hCaptcha, and Turnstile.
* **Notifications and integrations** — email notifications, Mailchimp, Webhooks, and Amazon S3 file storage,
  all in the free version.
* **Extendable with Contactum Pro** — payment forms (13 gateways), recurring subscriptions, quizzes with
  scoring, CRM integrations, Google Sheets, Zapier, and more premium field types.

== Frequently Asked Questions ==

= Does Contactum store form submissions? =

Yes. Every submission is saved as an entry under **Contactum → Entries**, with search, filtering, and CSV
export — unlike plugins that only send an email and keep no record.

= Can I import my forms from another plugin? =

Yes. Go to **Contactum → Tools → Migrate from Other Plugins**. Contactum detects Contact Form 7, Gravity
Forms, WPForms, Ninja Forms, Caldera Forms, and Fluent Forms if they're installed, and imports their forms —
fields, labels, and settings — in one click. Running the import again only adds forms that weren't imported
before, so it's safe to re-run.

= Do I need reCAPTCHA to stop spam? =

No. Every form already includes an invisible honeypot field and a minimum-time-to-submit check that block
obvious bot submissions automatically, with no setup and no impact on real visitors. reCAPTCHA, hCaptcha, and
Turnstile are available as additional, optional layers.

= Does the free version support payments? =

Payment fields and gateways are part of Contactum Pro, which adds 13 payment gateways, recurring
subscriptions, and coupon codes. The free version covers form building, entries, notifications, and spam
protection.
